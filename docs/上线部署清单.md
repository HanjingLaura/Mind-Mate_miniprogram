# Mind-Mate 微信小程序上线部署清单

## 当前结论

- 小程序 AppID 已配置为 `wx2f44eb1fa8419a3d`。
- 小程序备案号为 `京ICP备2026048276号-1X`，微信认证与类目已完成。
- 当前商品是 `¥1.99 / 30天` 的一次性 VIP 权益，不是自动续费产品。
- 普通小程序支付没有额外“商品 ID”。代码会自动生成商户订单号，微信下单后返回 `prepay_id`。
- 订阅消息需要一个在微信公众平台选定的模板 ID；模板关键词必须与服务端发送字段一致。
- 小程序备案通过不等于支付权限已开通。仍需完成小程序认证、商户号开通小程序支付权限、商户号与 AppID 绑定。

## 1. 从微信后台取得参数

### 小程序后台（mp.weixin.qq.com）

1. 在「开发管理 / 开发设置」确认 AppID 与项目一致。
2. 取得 AppSecret，填入云托管环境变量 `WECHAT_SECRET`。不要写进小程序前端或 Git。
3. 在「功能 / 订阅消息」从公共模板库选择提醒模板并取得模板 ID。
4. 当前服务端发送两个关键词：
   - `thing1`：提醒内容，最多发送 20 个字符。
   - `time2`：提醒时间。
5. 所选模板的关键词编号必须正好是 `thing1`、`time2`；若后台模板编号不同，需要同步修改 `backend/services/scheduler_service.py`。

### 微信支付商户平台（pay.weixin.qq.com）

1. 开通 JSAPI/小程序支付权限，并把商户号绑定到本项目 AppID。
2. 记录商户号：`WECHAT_MCHID`。
3. 在「账户中心 / API安全」设置 32 字符 API v3 密钥：`WECHAT_APIV3_KEY`。
4. 申请商户 API 证书，记录证书序列号：`WECHAT_CERT_SERIAL_NO`。
5. 保存商户私钥 `apiclient_key.pem`，并在「微信支付公钥」中下载微信支付公钥、记录公钥 ID。

私钥禁止发到聊天、提交 Git 或打进 Docker 镜像。云托管推荐把 PEM 文件转为 base64 后分别保存到环境变量：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes('apiclient_key.pem'))
[Convert]::ToBase64String([IO.File]::ReadAllBytes('wechatpay_public_key.pem'))
```

对应变量为 `WECHAT_PRIVATE_KEY_B64` 和 `WECHAT_PAY_PUBLIC_KEY_B64`；公钥 ID 填入 `WECHAT_PAY_PUBLIC_KEY_ID`。新商户默认采用公钥模式，项目已优先支持此模式。

## 2. 云托管服务配置

确认小程序实际绑定的云环境和服务名称。当前本地待确认值为：

- `CLOUD_ENV_ID=cloud1-5gf7rfg7475f222b`
- `CLOUD_SERVICE_NAME=mindmate-miniprogram`

后端从 `backend/Dockerfile` 构建。云托管服务至少配置以下环境变量：

```text
DASHSCOPE_API_KEY
BAILIAN_BASE_URL
BAILIAN_MODEL
LLM_PROVIDER=auto
ZHIPU_API_KEY
ZHIPU_BASE_URL
ZHIPU_MODEL
APP_ENV=production
APP_SECRET
ADMIN_SECRET_KEY
ADMIN_BYPASS_ENABLED
WECHAT_APPID
WECHAT_SECRET
WECHAT_SUBSCRIBE_TEMPLATE_ID
WECHAT_MCHID
WECHAT_APIV3_KEY
WECHAT_CERT_SERIAL_NO
WECHAT_NOTIFY_URL
WECHAT_PRIVATE_KEY_B64
WECHAT_PAY_PUBLIC_KEY_ID
WECHAT_PAY_PUBLIC_KEY_B64
DATABASE_URL
```

其中：

- 正式环境必须设置 `ADMIN_BYPASS_ENABLED=false`。内测升级接口默认关闭，不能用仓库历史中的示例暗号。
- `WECHAT_NOTIFY_URL` 必须是微信支付服务器能从公网访问的 HTTPS 地址，例如 `https://实际公网域名/api/pay/callback`。仅能通过 `wx.cloud.callContainer` 访问的内网地址不能接收支付回调。
- `DATABASE_URL` 必须指向持久化 MySQL/PostgreSQL。不要在云托管使用默认 SQLite；容器重启或扩容会造成订单、用户和任务数据丢失或不一致。
- 配置变更后重新部署版本，并访问 `/health`，预期返回 `{"status":"ok"}`。

## 3. 生成小程序生产配置

编辑 `miniprogram/.env`，填入订阅模板 ID，并确认云环境 ID 和服务名，然后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-miniprogram-config.ps1
```

脚本会生成 `miniprogram/utils/config.generated.js`。此文件被 Git 忽略，但会参与微信开发者工具本地预览和上传。

## 4. 上线前真机验收

1. 新用户微信登录成功，不能进入 `dev_` 开头的开发身份。
2. 添加、完成、删除任务后重启小程序，数据仍存在。
3. 点击订阅通知能弹出授权框；同意后后端能记录授权。
4. 用真实微信支付 `¥1.99`，确认：下单成功、收银台金额正确、回调状态为 paid、VIP 到期日增加 30 天。
5. 重复支付回调不会重复延长权益；错误金额或错误 openid 的回调会被拒绝。
6. 云托管日志中无 AppSecret、API v3 密钥、私钥或完整支付报文。
7. 微信后台已完成隐私保护指引、服务类目、客服与支付相关运营资料配置。
